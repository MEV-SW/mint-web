## 화면별 정의
### 1. 이슈 탐색
- **구성**: 화면을 영역으로 나눠 계층으로. 무엇이 한 덩어리인지·무엇이 반복되는지·무엇이 없을 수 있는지까지.
  ```
  상단  페이지 제목·설명
  도구  검색 입력·카테고리 필터·필터 초기화
  본문  이슈 카드 반복
        └ 카드: 제목 / 준비된 요약 또는 준비 상태 / 갱신 시각 / 공개 기사 수 / 출처 수
  하단  페이지 이동
  ```
- **표시 데이터**: [B1](https://github.com/MEV-SW/mint-server/issues/4) `GET /api/v1/stories`의 id, title, summary, summary_status, article_count, source_count, updated_at, total, page, page_size. 추적 여부·새 변화 배지는 이 카드에 포함하지 않는다. 출처 수는 확실성 점수처럼 표시하지 않는다. 요약 pending은 '요약 준비 중', unavailable은 '요약을 표시할 수 없습니다'로 구별한다.
- **액션**: 검색 제출·카테고리 변경 시 page=1. URL query는 q, category_id, page를 사용하고([newsListState.ts](https://github.com/MEV-SW/mint-web/blob/main/src/utils/newsListState.ts) 기존 패턴과 동일한 구조) page_size는 20으로 고정한다. 새 검색은 스크롤 상단부터 시작한다. 이슈 선택은 `/issues/:storyId`로 이동한다 — 상세는 [W2](https://github.com/MEV-SW/mint-web/issues/12)의 계약이며 이 카드에서 별도 상세를 만들지 않는다. W2 연동 전에는 사용자 대상 기능을 활성화하지 않는다. 뒤로가기는 URL 검색 조건·페이지·기존 스크롤 위치를 복원한다. 데이터 갱신으로 그 위치가 사라지면 유효한 위치로 복원한다.
- **상태**: 최초 로딩은 목록 골격. 전체 빈 목록(수집된 이슈 없음)과 검색 결과 없음(조건 완화·초기화 액션 제공)을 구별한다. 오류는 재시도, 오프라인은 네트워크 상태 안내를 제공한다. 재조회 중에는 이미 받은 목록을 유지하며 갱신 중임을 표시하고, 실패한 검색의 이전 목록을 새 검색 결과처럼 표시하지 않는다. 인증 만료는 기존 로그인 경로, 403은 접근·기능 비활성 안내, 503은 재시도. 서버 오류 detail 외 내부 스택은 표시하지 않는다. 작은 화면에서도 검색·필터·카드·페이지 이동 순서를 유지하며, 키보드 포커스가 보이고 검색·카테고리·페이지 이동에 접근 가능한 이름을 제공한다. 로딩·오류는 보조기술로 식별 가능해야 한다.
- **권한**: 기존 로그인 사용자. 실제 게시물 접근 범위는 서버가 결정한다. API count를 권한 밖 데이터를 추정하는 값으로 보충하지 않는다.

flag 제안: `VITE_ISSUE_RADAR_ENABLED` 기본 OFF. OFF일 때 메뉴를 숨기고 직접 `/issues` 진입은 비활성 안내. 서버 flag가 OFF이면 API 403을 처리한다. flag ON/OFF 조합은 릴리즈 구성표에서 함께 확인한다.
