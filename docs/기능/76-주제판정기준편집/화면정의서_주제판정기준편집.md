## 화면별 정의

### 1. 주제 관리 — 선택 주제 상세
- **구성**: 기존 섹션 순서에서 "관련성 키워드" 바로 아래에 두 섹션을 넣는다.
  ```
  선택 주제 헤더 (이름 · 홈에 표시)
  표시 방식           (기존)
  관련성 키워드        (기존 — 문구만 조정)
  판정 기준           (신규) 여러 줄 입력 + 저장 버튼
  제목 제외어          (신규) 칩 반복 + 입력
  소스 배정           (기존)
  ```
- **표시 데이터**
  - 관련성 키워드 설명: `수집·표시에서 이 주제의 글인지 판별하는 신호입니다. 영문 약어는 단어 단위로 비교합니다.` (최대 60개)
  - 판정 기준: `relevance_criteria`. 비어 있으면 placeholder `예) 관련 있음: … / 관련 없음: …`.
    설명 `AI가 수집 후보를 이 주제로 볼지 판단할 때 그대로 읽는 기준입니다. 비우면 주제 이름과 관련성 키워드만으로 판단합니다.`
  - 제목 제외어: `exclude_terms` 칩. 설명 `제목에 이 단어가 있고 관련성 키워드가 없으면 수집하지 않습니다. 이미 저장된 글은 숨기지 않습니다.` (최대 40개)
- **액션**
  - 판정 기준: 입력 후 `기준 저장` → `PATCH /api/v1/editions/{id}` `{ relevance_criteria }`. 입력값이 저장값과 같으면 버튼 비활성. 성공 시 기존 toast `주제 설정을 저장했습니다.`
  - 제외어 칩 ×: 해당 단어를 뺀 목록으로 `PATCH … { exclude_terms }`.
  - 제외어 입력 후 Enter: 중복 없이 추가해 `PATCH … { exclude_terms }`.
  - 실패 시 서버 detail을 err toast(기존 `주제 설정 저장에 실패했습니다.`).
- **상태**
  - 다른 주제를 선택하면 판정 기준 입력은 그 주제의 저장값으로 바뀐다(저장 안 한 입력은 버린다).
  - 저장 중에는 `기준 저장` 비활성.
  - 개수·길이 초과(422)는 err toast.
- **권한**: 기존 선택 주제 상세와 같다 — 최고 관리자는 전체, 분야 편집장은 담당 주제.

### 2. 주제 관리 — 주제 추가 패널
- **구성**: 기존 `주제명`, `관련성 키워드` 입력 아래에 `판정 기준 (선택)` 여러 줄 입력을 추가한다. 제외어는 생성 후 상세에서 넣는다.
- **액션**: `등록` 시 `POST /api/v1/editions`에 `relevance_criteria`를 함께 보낸다. 성공 시 입력을 비운다.
- **권한**: 최고 관리자(기존과 같음).
