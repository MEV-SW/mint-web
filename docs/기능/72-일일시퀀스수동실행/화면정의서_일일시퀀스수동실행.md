## 화면별 정의

### 1. 소스 관리 — 수집 운영 영역
- **구성**: 카드 4장 2열 격자는 그대로다. 첫 카드만 바뀐다.
  ```
  [일일 수집 시퀀스]              [탐문 파이프라인]
   아이콘 / 제목 / 설명 한 줄
   우측 버튼 2개: 수집만 · 전체 실행
  [커뮤니티 탐문]                 [탐문 후보 삭제 기한]
  ```
- **표시 데이터**
  - 제목 `일일 수집 시퀀스`
  - 설명 `매일 05:30~08:10(KST) 자동 · 정리 → 전체 수집 → AI 발견 → 커뮤니티 탐문 → 리포트 (Slack 제외)`
- **액션**
  - `수집만`(soft): 기존 `지금 수집`과 같다 — `POST /api/v1/sources/crawl-all`, 같은 toast.
  - `전체 실행`(primary):
    1. 확인 창 `일일 작업 전체를 지금 실행할까요?\n정리 단계에서 보존 기간이 지난 미승인 후보와 만료 기사가 삭제됩니다. Slack은 전송하지 않습니다.`
    2. 확인 시 `POST /api/v1/jobs/daily-sequence`.
    3. 성공(202) 시 작업 목록을 다시 불러오고 info toast `일일 전체 시퀀스를 백그라운드에서 시작했습니다. 작업 패널에서 단계별 진행을 확인하세요.`
    4. 실패 시 서버 `detail`을 err toast로, 없으면 `일일 전체 시퀀스 요청 실패`.
    취소하면 아무 요청도 보내지 않는다.
- **상태**
  - 요청 중·다른 작업 진행 중: 두 버튼 모두 라벨 `…`, 비활성. 진행 중이면 기존 busy 배너와 title에 진행 중 작업 라벨.
    시퀀스가 도는 동안 작업 패널에 상위 작업(`일일 전체 시퀀스 (수동)`, `{n}/6 · 단계`)과 단계별 하위 작업이 차례로 나타난다.
  - 권한 없음: 카드는 보이되 두 버튼 비활성, title `총관만 실행할 수 있습니다.`
  - 409: err toast로 서버 메시지.
- **권한**: 두 버튼 실행은 총관(admin)만.
