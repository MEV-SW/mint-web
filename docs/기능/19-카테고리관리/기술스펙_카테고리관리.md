## 핵심 흐름 (시퀀스 1-2개)

정상 경로 — 카테고리 추가:
```mermaid
sequenceDiagram
    Admin->>Page: "카테고리 추가" 클릭 → Modal 열림
    Admin->>Page: 이름 입력 후 저장
    Page->>API: POST /api/v1/categories {name, sort_order}
    API-->>Page: 201 CategoryRead
    Page->>Page: react-query invalidate(['categories'])
    Page-->>Admin: Toast "카테고리를 추가했습니다"
```

실패 경로 — 사용 중인 카테고리 비활성화 시도:
```mermaid
sequenceDiagram
    Admin->>Page: "비활성화" 클릭
    Page->>API: DELETE /api/v1/categories/{id}
    API-->>Page: 409 {"detail":"이 카테고리를 참조하는 활성 소스가 있어..."}
    Page-->>Admin: Toast(err)에 서버 detail 그대로 표시, 목록은 그대로 유지
```
