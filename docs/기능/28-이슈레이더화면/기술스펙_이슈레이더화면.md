## 변경 범위

이 카드(W1)의 산출물은 화면정의서 자체다. **코드 변경 없음.**

W1이 정의한 5개 화면(이슈 목록 / 상세 / 변화 타임라인 / 1면 변화 밴드 / 관리자 병합·분리)은 각각 별도 카드에서 구현한다:
- [W2](https://github.com/MEV-SW/mint-web/issues/29) — 이슈 목록 + 상세
- [W3](https://github.com/MEV-SW/mint-web/issues/30) — 변화 타임라인
- [W4](https://github.com/MEV-SW/mint-web/issues/31) — 추적 on/off
- [W5](https://github.com/MEV-SW/mint-web/issues/32) — 1면 변화 밴드
- [W6](https://github.com/MEV-SW/mint-web/issues/33) — 관리자 병합·분리

실제 파일 단위 변경 범위·시퀀스·flag는 각 구현 카드의 기술스펙에서 적는다. 여기서 미리 확정해 각 카드가 공유하는 것만 남긴다:

- 라우팅: `/issues`(메인 내비, `ProtectedRoute`) — 사용자 화면. `/admin/issues`(`SuperAdminRoute`) — 관리자 화면. 신설 경로만이고 기존 `App.tsx` 구조는 그대로.
- 상태 관리: 기존처럼 `@tanstack/react-query`. 신규 라이브러리 없음.
- 디자인: `sample_design/MINT Daily.dc.html`(로컬, 디자이너 산출물) — 타임라인·배지 3종·1면 밴드 시각 스펙의 기준. 각 구현 카드가 해당 화면 영역만 참고.
